# 🚀 Featured Projects

## 📊 Project Management System – Spring Boot REST Backend
Architected a multi-user project management backend exposing 20+ REST APIs across 7+ domain entities, using DTOs and a layered MVC architecture with Hibernate/JPA over MySQL. Implemented JWT authentication and role-based authorization with Spring Security; built issue tracking, task discussions, team messaging, email invitations, and Razorpay subscription controls.
- **Tech Stack:** Java, Spring Boot, Spring Security + JWT, Hibernate/JPA, MySQL, Maven, Postman, Razorpay API
- **GitHub:** [Project-Management-application](https://github.com/ayush95922/Project-Management-application)

---

## 🚌 SmartRoute – Multi-Modal Transit Optimizer
A full-stack route comparison platform evaluating Bus, Walking, Cycling, and Car routes on travel time, distance, cost, and carbon emissions across 15+ routes in Indore. Implemented Dijkstra's algorithm for shortest-path optimization across a custom transit graph, with interactive maps via Leaflet.js and OpenStreetMap.
- **Tech Stack:** Java 17, Spring Boot 3.2, MongoDB Atlas, Spring Security + JWT, Leaflet.js, OpenStreetMap, Vanilla JS, Tailwind CSS
- **Live Demo:** [route-optimizer-ayush95.vercel.app](https://route-optimizer-ayush95.vercel.app/)
- **GitHub:** [Route-Optimizer](https://github.com/ayush95922/Route-Optimizer)

---

## 💊 Ewon Medicare – Medicine E-Commerce Platform
A full-stack online pharmacy marketplace supporting 10+ product SKUs with catalog, cart, checkout, and order management, secured with JWT-based authentication and role-based authorization. Integrated Razorpay for payment processing and built an admin dashboard for real-time inventory and order management.
- **Tech Stack:** Java, Spring Boot, Spring MVC, React.js (Vite), MySQL, JWT, Razorpay API
- **GitHub:** [medical-ecommerce](https://github.com/ayush95922/medical-ecommerce.git)
